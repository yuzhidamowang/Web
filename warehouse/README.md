# 食材库房

给食材供应商用的内部库房网站。老板可以在这里管库存、记出入库、维护客户，以及手工登记客户订单。

这不是客户下单的网店，没有购物车，也没有支付。订单来源目前固定为「手工录入」。数据里已经留了「客户下单」（`customer_order`），以后接客户自助下单时不用改表。

登记订单**不会**自动扣库存。备货、送达只改订单状态。货真正离开仓库时，到「出入库」登记出库。出库数量如果大于现存量，会被拒绝，库存不会变成负数。

## 环境

- Node.js 22 或更高
- npm

## 安装与运行

在仓库的 `warehouse` 目录：

```bash
cd warehouse
npm install
npm run dev
```

浏览器打开 <http://localhost:3000>。

生产构建：

```bash
npm run build
npm start
```

## 数据

第一次启动会在 `warehouse/data/warehouse.db` 生成 SQLite 数据库，并写入一批食材、客户、出入库流水和订单，方便直接演示。这个数据库文件不会提交到 git。删掉它再启动，会重新灌入种子数据。

## 页面

- `/` 首页概况
- `/inventory` 库存：搜索、按类别筛选、只看低于安全库存的品项，可新增和编辑
- `/movements` 出入库
- `/customers` 客户
- `/orders` 订单记录

品项字段包括名称、类别（蔬菜 / 肉类 / 干货 / 调料）、规格、单位（斤 / 公斤 / 箱 / 袋 / 瓶）、当前数量、库位、安全库存、批次、保质期。
